# 予定（iPhone向け 予定入力PWA）

自分専用のシンプルな予定アプリ。無料・アカウント不要・サーバー不要。
静的ファイルだけで動くので、GitHub Pages にそのまま置けます（ビルド不要）。

## できること

| 機能 | 内容 |
|---|---|
| 単発の予定 | 日付をタップ → カテゴリをタップ → 保存（＋ボタンからも可） |
| 毎週ルール | バイト・ゼミ。曜日を複数選択、時刻 or 終日、開始日・終了日 |
| ルールの切り替え | 「複製」→ 曜日と開始日を変えて保存すると、元のルールは開始日の前日で自動終了（過去分は残る） |
| 休み（スキップ） | 月表示で日付 → 予定をタップ →「この日だけ休みにする」 |
| 臨時シフト | 同じ画面の「この日に臨時のバイトを追加」、または単発でバイトを追加 |
| ゼミ発表 | 日付を選ぶだけで、その日の通常ゼミの時刻を自動で引き継ぐ。通常ゼミは自動で非表示。月表示ではオレンジ枠＋★ |
| 表示 | 月表示（カテゴリ色の点）／一覧表示（下のタブで切り替え、左右スワイプで月移動） |
| 保存 | 端末内の IndexedDB。起動時に `navigator.storage.persist()` を呼ぶ |
| iPhoneカレンダー | 設定 →「全予定をカレンダーへ」で .ics を共有／ダウンロード。各予定の編集画面から1件だけ送ることも可 |
| バックアップ | 設定 →「JSONで書き出す」／「JSONを読み込む」 |

### カテゴリごとの決まり

| カテゴリ | 時刻 | 通知 | 毎週ルール |
|---|---|---|---|
| バイト | 終日 | なし | ○ |
| 誕生日 | 終日・毎年 | 前日 23:55（設定で変更可） | — |
| ゼミ | あり | なし | ○ |
| ゼミ発表 | 通常ゼミから引き継ぎ（変更可） | 任意 | — |
| 映画／遊び／その他 | 任意 | 任意（オン／オフ） | — |

タイトルは空でもOK（カテゴリ名が使われます）。

### 通知について
PWA から直接通知は出さず、**iPhone標準カレンダーに登録した予定（VALARM）で通知**されます。
通知時刻は「設定」で変更でき、.ics を書き出すときに計算されます。

- 誕生日: 当日 0:00 の何分前か → 既定は `TRIGGER:-PT5M`（前日23:55）
- 時刻ありの予定: 既定 30分前
- 終日の予定: 既定 当日 9:00

設定を変えたら、もう一度「全予定をカレンダーへ」を実行してください。

## .ics の中身（iPhoneカレンダー連携）

- 予定ごとに `UID:<id>@yotei.pwa` を付けるので、再登録しても同じ予定として扱われます。編集するたびに `SEQUENCE` が上がります
- 終日予定は `DTSTART;VALUE=DATE`、時刻あり予定は `TZID=Asia/Tokyo`（VTIMEZONE 同梱）、長さは1時間
- 誕生日は `RRULE:FREQ=YEARLY`
- 毎週ルールは `RRULE:FREQ=WEEKLY;BYDAY=MO,WE,FR;UNTIL=...`
- スキップした日と、ゼミ発表がある日の通常ゼミは `EXDATE` で除外
- バイト・ゼミは VALARM なし

注意: アプリで**削除**した予定は .ics では消せません。iPhoneのカレンダー側でも削除してください。

## チャットで作った予定を取り込む

設定 →「JSONを読み込む」で、大きな貼り付け欄にJSONを貼る（「クリップボードから貼り付け」ボタンあり）→「取り込む」。
既存の予定は消えず、`uid` が同じ予定だけ上書きされます。```json ～ ``` で囲まれたままでも読めます。

読み込み画面の「書式をコピー」を押すと、チャットに渡す指示文＋書式見本がコピーされます。

```json
{
  "items": [
    { "type": "single", "category": "映画", "title": "〇〇を観る", "date": "2026-12-05", "time": "18:30", "notify": true },
    { "type": "single", "category": "誕生日", "title": "母の誕生日", "date": "2026-03-14" },
    { "type": "single", "category": "ゼミ発表", "date": "2026-12-10" },
    { "type": "weekly", "category": "バイト", "days": ["月", "水", "金"], "start": "2026-12-01", "end": "2027-03-31" },
    { "type": "weekly", "category": "ゼミ", "days": ["木"], "time": "13:00", "start": "2026-10-01", "end": "2027-01-31" }
  ]
}
```

- `time` を省略すると終日。ゼミ発表で省略すると、その日の通常ゼミの時刻を引き継ぎます
- `days` は `["月","水"]` / `"月水"` / `["MO","WE"]` / `[1,3]` のどれでもOK
- 毎週ルールの休みは `"skips": ["2026-12-25"]`
- 同じ予定を後で上書きしたいときは `"uid": "任意の文字列"` を付けておく

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例: `yotei`。Public なら無料で Pages が使えます）
2. このフォルダの中身（`index.html`, `style.css`, `sw.js`, `manifest.json`, `.nojekyll`, `js/`, `icons/`）をリポジトリ直下にアップロード
   - ブラウザなら「Add file → Upload files」にフォルダごとドラッグ
   - コマンドなら:
     ```sh
     cd yotei
     git init -b main
     git add .
     git commit -m "first commit"
     git remote add origin https://github.com/<ユーザー名>/yotei.git
     git push -u origin main
     ```
3. リポジトリの **Settings → Pages** で「Source: Deploy from a branch」「Branch: main / (root)」を選んで Save
4. 1〜2分待つと `https://<ユーザー名>.github.io/yotei/` で開けます

予定データは各端末のブラウザ内だけに保存され、GitHub には送られません。

### 更新するとき
ファイルを直したら `sw.js` の `const VERSION = 'yotei-v1';` の数字を上げてからアップロードしてください。
アプリを開くと裏で新しい版を取得し、**次に開いたとき**から反映されます。

## iPhone の Safari で「ホーム画面に追加」

1. iPhone の **Safari** で `https://<ユーザー名>.github.io/yotei/` を開く（Chrome などでは不可）
2. 画面下の **共有ボタン**（□に↑）をタップ
3. 下にスクロールして **「ホーム画面に追加」** をタップ
4. 名前（「予定」）を確認して右上の **「追加」**
5. ホーム画面のアイコンから起動 → 全画面アプリとして動き、オフラインでも使えます

ポイント:
- 予定は「ホーム画面のアプリ」と「Safariのタブ」で**別々に保存**されます。普段は必ずホーム画面のアイコンから開いてください
- 機種変更や念のためのバックアップは、設定 →「JSONで書き出す」→ ファイルに保存

## iPhoneカレンダーへ登録する手順

1. 設定タブ →「📅 全予定をカレンダーへ（共有）」
2. 共有シートで「カレンダー」を選ぶ（出ない場合は「“ファイル”に保存」→ ファイルアプリで .ics を開く）
3. 「すべてを追加」→ 追加先のカレンダーを選ぶ

うまくいかないときは「.ics をダウンロード」→ ダウンロード一覧から開いてください。

## ファイル構成

```
index.html      画面の骨組み
style.css       見た目（スマホ前提・ダークモード対応）
manifest.json   PWA設定
sw.js           Service Worker（オフライン対応）
js/app.js       画面・操作
js/util.js      カテゴリ定義・日付ヘルパー・既定の設定
js/db.js        IndexedDB
js/occur.js     単発・毎年・毎週ルールを日ごとに展開（スキップ／ゼミ発表の非表示）
js/ics.js       .ics 生成
js/data.js      JSONバックアップ・読み込み
icons/          アイコン（make_icons.py で再生成可）
```

## 手元で動かす

```sh
cd yotei
python -m http.server 8000
```
→ ブラウザで http://localhost:8000/ （`file://` で直接開くと Service Worker と モジュールが動きません）
